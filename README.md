# Toy Haven

Run locally (needed for PWA / Lighthouse - do NOT open index.html by double-clicking):
1. VS Code -> install "Live Server" -> right-click index.html -> Open with Live Server
2. Or in a terminal inside this folder: `python -m http.server 8000` then open http://localhost:8000

Deploy: push the contents of this folder to a GitHub repo (index.html at the root) and enable GitHub Pages.
